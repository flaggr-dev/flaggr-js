# Security policy

Please report security vulnerabilities in `@flaggr/sdk` or `@flaggr/evaluator` privately: use GitHub's [Report a vulnerability](https://github.com/flaggr-dev/flaggr-js/security/advisories/new) button on this repository's Security tab, or email [security@flaggr.dev](mailto:security@flaggr.dev). Don't open a public issue or pull request for them.

Include the package and version, what you found, and the steps to reproduce it.
